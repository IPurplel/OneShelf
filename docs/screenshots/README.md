# Screenshots

The pictures in the main README are taken from a real, running OneShelf, not mocked up.

* **Demo library.** Only public-domain books from Standard Ebooks and Creative Commons books from Hindawi
  are shown, so no commercial cover art appears here. The comic and webtoon sources were switched off while
  the library was filled and the pictures were taken, and switched back on for the *Sources* picture.
* **Sample data.** The reading goal, the streak, the progress in *Pride and Prejudice* and the three highlighted
  quotes were created for the pictures. The Arabic picture uses shelf names written in Arabic, since shelf names
  are whatever the reader types.
* **Size.** 1280 pixels wide, as a normal browser window; reduced to 256 colours to keep the repository small.

To retake them, run OneShelf against an empty data folder, add a few public-domain books, and capture the pages
with any browser automation tool at that window size.
